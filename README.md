# Claim Frequency Modeling

## Overview

This project develops a claim frequency model using the French Motor Third-Party Liability (freMTPL2) dataset.

The analysis compares:

- Poisson Regression
- Negative Binomial Regression

The objective is to estimate the expected number of insurance claims based on policyholder and vehicle characteristics and identify the model that best captures claim frequency.
